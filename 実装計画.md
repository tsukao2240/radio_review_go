## 重要な実装メモ（別セッション向け）

### Radiko認証フロー
```
1. GET https://radiko.jp/v2/api/auth1
   ヘッダー: X-Radiko-App: pc_html5, X-Radiko-App-Version: 0.0.1, X-Radiko-User: test-stream
   → レスポンスヘッダーから X-Radiko-AuthToken, X-Radiko-KeyLength, X-Radiko-KeyOffset 取得

2. storage/keys/radiko_auth_key.txt を Base64デコード
   → KeyOffset から KeyLength バイト切り出し
   → Base64エンコードして部分キー生成

3. GET https://radiko.jp/v2/api/auth2
   ヘッダー: X-Radiko-AuthToken, X-Radiko-PartialKey, X-Radiko-Location: 35.6897,139.6922 (東京)
   → レスポンスボディ: "JP13,<areaId>,..."

4. Redisにキャッシュ: SET radiko_auth_token_{areaId} <token> EX 3300
```

### 録音owner_key
- ログイン済み: `user_{userID}`（例: `user_42`）
- ゲスト: `session_{sessionID}`（例: `session_abc123`）
- Redis録音情報に必ず含め、取得時に照合する

### html/template の注意点
- XSS対策で `{{ .Var }}` は自動エスケープ
- 生HTML出力が必要な場合は `template.HTML` 型を使う
- テンプレートのベースレイアウト: `{{ template "base" . }}` スタイル

### DBコネクション設定

```go
db.SetMaxOpenConns(25)
db.SetMaxIdleConns(25)
db.SetConnMaxLifetime(5 * time.Minute)
```
