# 保存先フォルダの設定

1. メニューの「設定」を開く。
2. 「保存先フォルダを選択」で保存先を選び、書き込みを許可する。
3. 録音履歴の「ダウンロード」で指定フォルダへ直接保存する。

設定はブラウザ/PWA内に記憶する。別のブラウザやプロファイルには共有しない。ブラウザ再起動後などはアクセス許可の確認が出る場合がある。書き込みを許可しない場合、元の録音は保持する。

同名ファイルがあれば「 (2)」「 (3)」を付けて保存し、既存ファイルを上書きしない。複数タブ間でも名前の割り当てを直列化する。

設定画面の「毎回、保存先を選ぶ」で保存先指定を解除できる。保存済みファイルは削除しない。保存先未設定の場合は従来の保存ダイアログを利用する。フォルダ指定に非対応のブラウザでは通常のダウンロードを利用する。

音声の書き込み完了後に保存完了APIを呼ぶ。成功すればサーバー上の元の録音を削除し、一覧も更新する。キャンセル、権限拒否、書き込み失敗では削除しない。
