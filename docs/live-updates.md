# 画面の即時更新

- 操作APIの成功後、現在の画面を部分更新する。録音・お気に入り・予約の削除、投稿・通知などで共通利用する。
- バックグラウンド処理や別ウィンドウでの変更は `/api/live` のSSE通知で追従する。検知間隔は500ms。描画には通信時間が加わる。
- 保存先ダイアログを開き、端末への保存完了後に削除APIを呼び、その結果を画面へ反映する。キャンセルでは録音を残す。
- 再生中のプレーヤーは同じ要素を維持し、入力中のフォームはフォーカスが外れるまで差し替えを保留する。
- 通知の切断時は再接続し、その間は3秒間隔の更新へ切り替える。バックグラウンドのページは通知を止め、表示復帰時に更新する。
